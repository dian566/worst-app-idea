## The pitch

> Introducing NapTrack Pro: an app that tracks exactly how long your phone naps while you sleep, then charges you $4.99 a month to remind you it was asleep too.

Your phone already sleeps. Now it can bill you for it.

## How it works

`main.py` is a small deterministic program: it writes that one sentence,
byte-identical on every run, to `/output/entry.txt`. No randomness, no clock,
no network, no input — just the pitch.

```sh
python3 main.py
cat /output/entry.txt
```
