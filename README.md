An entry for the make.fun bounty **The Worst App Idea Ever Pitched** — a single sentence, no more than 240 characters, pitching the worst and most useless app idea imaginable. See the bounty at [make.fun](https://make.fun).

## The pitch

> Introducing NapTrack Pro: an app that tracks exactly how long your phone naps while you sleep, then charges you $4.99 a month to remind you it was asleep too.

Your phone already sleeps. Now it can bill you for it.

## Running it

`main.py` is a tiny deterministic program: it writes that one sentence, byte-identical on every run, to `/output/entry.txt`. No randomness, no clock, no network, no input — only the pitch.

```sh
python3 main.py
cat /output/entry.txt
```
